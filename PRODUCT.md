# Product

## Register

product

## Users

Developers using BB who want to talk with the agent already attached to a working thread without creating a second, competing work session.

## Product Purpose

Voice Presence provides low-latency spoken conversation for one explicit BB thread. Realtime voice handles quick dialogue, the owner thread handles durable work, and the thread's provider output returns to the same call as narration.

## Brand Personality

Native, calm, explicit. The interface should feel like a compact BB control surface, not a separate assistant product.

## Anti-references

Obstructive floating overlays, ambiguous call ownership, hidden connection state, decorative voice visualizations that dominate the conversation, and controls that silently change behavior across threads.

## Design Principles

- Keep the thread and its messages visually primary.
- Make call ownership and lifecycle obvious at the point of use.
- Use familiar compact controls and BB's existing visual vocabulary.
- Show failures and disconnections as actionable state, never as silent absence.
- Let motion communicate voice activity without becoming the interface.

## Accessibility & Inclusion

Use semantic call controls, visible status text, polite live announcements, keyboard-accessible actions, host theme tokens, and reduced-motion-compatible presentation. Never rely on color or animation alone to communicate call state.
